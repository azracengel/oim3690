## API mashup

My API mashup idea is a travel recommendation tool for students that combines weather forecast information from Open-Meteo with destination information from GeoNames.

The tool would take weather data from Open-Meteo and location information from GeoNames, then ask AI to recommend activities based on the destination and weather conditions.

I think this would be useful for students who are traveling because it would help them plan activities based on the weather instead of having to search through multiple websites.
