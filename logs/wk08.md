# Week 8 Reflection

## What I Worked On
This week, I worked on my Mini Project 2, StudyFlow, which is a study session tracker. I used HTML, CSS, and JavaScript to create a tool that lets users log study sessions, see their weekly study time, and delete or reset sessions. I also practiced debugging JavaScript and understanding how to test whether my code works correctly.

## What I Found Difficult
I found it challenging to understand how different parts of my JavaScript code work together, especially how the study sessions are saved and how the page updates when something changes. I also had to make sure my tracker worked in different situations, such as when there were no sessions, when someone entered invalid information, and after resetting the data.

## Something New I Learned
I learned more about using localStorage to save information even after refreshing a webpage. I also learned that testing a website means checking more than whether it looks good. It is important to test different situations and make sure every button and function works correctly.

## JS I Don't Understand

1. `localStorage.setItem()` — I understand that it saves information, but I still want to understand exactly how the browser stores it.

2. `JSON.stringify()` and `JSON.parse()` — I find it confusing why we need to convert arrays into strings before saving them and then convert them back.

3. `sessions = []` — I want to understand better how resetting an array affects the information displayed on the page.

## What I Noticed About AI
AI helped me build StudyFlow and understand parts of my JavaScript code that I found confusing. However, I realized that even when AI creates working code, I still need to test it myself. This week showed me that debugging and understanding what the code actually does are just as important as getting the final website to work.
