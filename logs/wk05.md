
# Week 5 Reflection

## What I Worked On
This week, I worked on creating a to-do list app using HTML, CSS, and JavaScript. I learned how JavaScript can make a website interactive by allowing users to add and remove tasks.

## What I Found Difficult
I found JavaScript harder to understand than HTML and CSS because I was unfamiliar with how functions and event listeners work together.

I learned that JavaScript can respond to user actions, such as clicking a button or submitting a form.

## JS I Don't Understand (from the To-Do App)

2. `event.preventDefault()` — I am confused about what the default behavior of a form is and why we need to prevent it.

3. `document.createElement('li')` — I want to understand how JavaScript creates new HTML elements without writing them directly in the HTML file.
