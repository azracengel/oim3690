# Week 4 Reflection

## What I worked on
- I worked on improving the layout of my website with CSS and making the page responsive.
- I practiced using Flexbox and worked on making the navigation look different on smaller and larger screens.

## What gave me trouble
- The responsive navigation was confusing at first because I had to understand how the layout changes depending on the screen size.
- I also had trouble figuring out which CSS rules should apply to mobile versus desktop.

## Something new I learned
- I learned how Flexbox can be used to organize elements and control their position on a page.
- I also learned how media queries can change the design at different screen sizes instead of having the same layout everywhere.

## Working with AI
- AI helped me understand how to structure the responsive CSS when I was unsure where the media query should go.
- I noticed that when AI gave me CSS, I still had to compare it with my HTML classes and test it with Live Server because the code would not necessarily match my page automatically.
