## What I Learned

This exercise helped me understand how individual lines of JavaScript affect a website. I learned that event listeners respond to user actions, appendChild adds elements to the page, and setting an input's value to an empty string clears it. I also realized that even changing one line of code can affect how the entire app works.

The most challenging part was understanding why removing certain lines caused different problems. At first, I did not fully understand how the JavaScript connected to the HTML. Testing each line separately helped me understand the code better.
