# Week 7 Reflection

## What I Worked On
This week, I learned more about JavaScript, especially variables, functions, arrays, and loops. I practiced using JavaScript to perform calculations and learned how arrays can store multiple values. I also worked on understanding how loops can help us repeat actions without writing the same code multiple times.

## What I Found Difficult
I found it difficult to understand how loops work and how JavaScript goes through each item in an array. I also sometimes get confused about when to use different types of variables and how functions return values.

## Something New I Learned
I learned that arrays can store multiple pieces of information in one variable and that loops make it easier to work with that information. I also learned how conditional statements allow JavaScript to make decisions based on different conditions.

## JS I Don't Understand

1. `for (let i = 0; i < songs.length; i++)` — I still find it confusing how the loop knows when to stop and how the value of `i` changes each time.

2. `return` — I don't fully understand the difference between returning a value from a function and displaying something on the webpage.

3. `songs.push(newSong)` — I want to understand better how adding a new item changes an existing array.
