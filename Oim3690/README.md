# To-Do App

This is a simple To-Do application built using plain HTML, CSS, and JavaScript. The app allows users to add, remove, and manage their tasks efficiently.

## Project Structure

```
Oim3690
├── css
│   └── todo.css       # Styles for the To-Do app
├── js
│   └── todo.js        # JavaScript logic for the To-Do app
├── todo.html          # Main HTML file for the To-Do app
└── README.md          # Documentation for the project
```

## Features

- Add new tasks to the list
- Remove tasks from the list
- Clear all tasks

## Usage

1. Open `todo.html` in your web browser.
2. Enter a task in the input field and click "Add Task" to add it to your list.
3. Click the "Remove" button next to any task to delete it from the list.
4. To clear all tasks, click the "Clear All" button.
